# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SvagView, please report it responsibly:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Please open a [GitHub Security Advisory](https://github.com/vaibhav-upadhyay/SvagView/security/advisories/new) or contact the maintainers privately.
3. Provide details regarding:
   - The nature of the vulnerability.
   - Steps to reproduce or proof-of-concept SVG file.
   - The affected version and operating system.
4. You will receive an acknowledgment within 48 hours, followed by updates as the issue is investigated and patched.
